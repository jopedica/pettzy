# 📚 Projeto Integrador II — Ciência da Computação · UniCEUB

Bem-vindo ao repositório do **Projeto Integrador II**, desenvolvido no curso de **Ciência da Computação** do **Centro Universitário de Brasília (UniCEUB)**.  
Este projeto aplica conceitos de Engenharia de Software, Arquitetura de Sistemas e Programação no desenvolvimento de uma solução completa e documentada.

---

## 🚀 Sobre o Projeto

O objetivo central do Projeto Integrador II é **conceber, projetar e implementar um sistema funcional**, passando pelas etapas de:

- Levantamento e análise de requisitos  
- Modelagem do sistema (UML, MER, protótipos)  
- Definição da arquitetura  
- Implementação do software  
- Banco de dados  
- Testes  
- Documentação final

---

## 🧩 Objetivo Geral

Desenvolver uma aplicação que resolva um problema real por meio de boas práticas de engenharia, código limpo, documentação estruturada e arquitetura escalável.
